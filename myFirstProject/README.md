# How to start

### Shortcut: Using Maven-Springboot plugin

```bash
mvn spring-boot:run
```

### Longcut:

#### Step 1: Do Maven Clean

```bash
mvn clean
```


#### Step 2: Do Maven Package 

```bash
mvn package
```

#### Step 3: Start the Server

```bash
cd target
java -jar myFirstProject-0.0.1-SNAPSHOT.jar
```
